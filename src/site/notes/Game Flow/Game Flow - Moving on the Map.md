title: Game Flow - Moving on the Map
---

When the game begins, a map like the one below is presented to players. The locations should be based on the locations (towns, dungeons, or terrains) generated by the Campaign Creator tool. See [[Campaign Creator Tool - About]] for more information. 

Locations are numbered 1-N where N is the number of locations generated for the campaign. The party can only travel to locations adjacent to their current location. The position of each location on the map is entirely up to the discretion of the DM but is recommended by the names of the generated locations.

When the game begins, the party always starts in location 1 (which is always located in Wales). One of these locations *must* be Camelot, which is the final location of the campaign.
